# E-commerce Sales Analysis using MySQL and Power BI

## Project Overview
This project focuses on analyzing e-commerce sales data using MySQL and Power BI to understand customer activity, product performance, order trends, and revenue.

## Tools & Technologies
- MySQL
- MySQL Workbench
- Power BI Desktop
- SQL
- DAX

## Key Performance Indicators (KPIs)

| KPI | Result |
|---|---:|
| Total Customers | 12 |
| Total Orders | 20 |
| Customers with Orders | 12 |
| Total Products | 10 |
| Total Revenue | 78,335.90 |

## SQL Analysis
- Retrieved customer, product and order data.
- Calculated total customers and products.
- Counted total orders.
- Calculated total revenue.
- Identified customers who placed orders.

## Power BI Dashboard
Created an interactive dashboard to present key business performance indicators.

## Business Objective
To understand e-commerce business performance through data analysis and support better business decisions.
